## 1. Концепция и видение

### Краткое описание

Stellara — это развлекательное iOS-приложение в жанре «AI-оракул», которое объединяет ностальгию по магическому шару-предсказателю (Magic 8 Ball) с возможностями современных языковых моделей. Пользователь задаёт любой вопрос, выбирает персонажа-оракула с уникальным характером — и получает осмысленный, контекстный, забавный или мистический ответ.

### Ключевая идея

Не серьёзная астрология (эта ниша занята Co–Star, The Pattern), а **мистическое развлечение с характером**. Пользователь приходит за вайбом, юмором и ежедневной дозой «магии», а не за наставлениями жизни.

### УТП (уникальное торговое предложение)

- **Бесконечный контент** — каждый ответ уникален благодаря AI
- **Персонажи с характером** — выбор стиля общения от драматичной гадалки до саркастичного оракула
- **Контекстная память** — оракул помнит твои вопросы и реагирует на паттерны
- **Микс жанров** — шар, гороскоп, Таро, совместимость в одном приложении
- **Лёгкий tone-of-voice** — приложение знает, что это игра, и не претендует на серьёзность

### Слоган-кандидаты

- "Звёзды на связи"
- "Спроси у вселенной. Получи ответ."
- "Твой карманный оракул"

## 3. Функциональность

### MVP (версия 1.0)

#### 3.1. Магический шар-предсказатель ⭐
- Главный экран с анимированным шаром
- Поле ввода вопроса (текст или голос)
- Жест «потрясти телефон» для активации
- AI генерирует ответ в стиле выбранного персонажа
- Ответ 1–3 предложения с лёгкой мистикой и юмором
- Контекстная память последних 3–5 вопросов

#### 3.2. Персонажи-оракулы
Минимум 3 персонажа на старте:
- **Зефира** — древний мудрый оракул, говорит загадками
- **Мадам Лу** — деревенская гадалка, прямолинейная и саркастичная
- **Космо** — современный астролог-хипстер, говорит на сленге

#### 3.3. Гороскоп дня
- Персонализированный, не шаблонный
- Учитывает имя, знак, последние вопросы
- Утреннее push-уведомление

#### 3.4. Карта Таро дня
- Колода Rider-Waite (public domain)
- Одна карта в день с интерпретацией
- Анимация переворота

#### 3.5. История предсказаний
- Все вопросы и ответы сохраняются локально
- Возможность отметить «сбылось / не сбылось»
- Поиск по истории

#### 3.6. Онбординг
- Запрос имени, даты рождения, знака зодиака
- Выбор любимого персонажа
- Туториал из 3 экранов

## 4. Архитектура

### Высокоуровневая схема

```
┌─────────────────┐
│   iOS App       │  SwiftUI, локальная БД
│   (клиент)      │
└────────┬────────┘
         │ HTTPS + DeviceCheck token
         ▼
┌─────────────────┐
│ Cloudflare      │  Rate limiting, валидация,
│ Worker          │  агрегация запросов
│ (бэкенд)        │
└────────┬────────┘
         │ API key (в секретах)
         ▼
┌─────────────────┐
│ Anthropic API   │  Генерация ответов
│ (Claude)        │
└─────────────────┘
```

### Принципы

- **Stateless бэкенд** — Worker не хранит состояние, всё в клиенте или в Cloudflare KV
- **Локальная история** — все вопросы и ответы остаются на устройстве (приватность + экономия)
- **Минимум сетевых запросов** — кэшируем гороскопы и карту дня на 24 часа
- **Graceful degradation** — если API недоступен, показываем заранее заготовленные «оффлайн-предсказания»

## 8. API и бэкенд

### Эндпоинты Cloudflare Worker

```
POST /v1/predict
  Body: { question, oracleId, history[], userContext }
  Headers: X-Device-Token (DeviceCheck)
  Response: { answer, predictionId }

POST /v1/horoscope/daily
  Body: { zodiacSign, name, recentTopics[] }
  Response: { content, validUntil }

  Body: { date, userId }
  Response: { cardName, isReversed, interpretation }

POST /v1/tarot/spread
  Body: { question, spreadType, cards[] }
  Response: { interpretation }

GET /v1/health
  Response: { status: "ok" }
```

### Псевдокод Worker (TypeScript)

```typescript
export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    // 1. Проверка DeviceCheck токена
    const deviceToken = request.headers.get('X-Device-Token');
    if (!await verifyDevice(deviceToken, env)) {
      return new Response('Unauthorized', { status: 401 });
    }

    // 2. Rate limiting через KV
    const rateLimitKey = `rl:${deviceToken}:${getDay()}`;
    const count = parseInt(await env.KV.get(rateLimitKey) ?? '0');
    if (count > getDailyLimit(isPro)) {
      return new Response('Rate limit', { status: 429 });
    }

    // 3. Маршрутизация
    const url = new URL(request.url);
    if (url.pathname === '/v1/predict') {
      return handlePrediction(request, env);
    }
    // ... другие эндпоинты

    // 4. Инкремент счётчика
    await env.KV.put(rateLimitKey, String(count + 1), { expirationTtl: 86400 });
  }
}

async function handlePrediction(request: Request, env: Env) {
  const { question, oracleId, history, userContext } = await request.json();

  const systemPrompt = getOraclePrompt(oracleId);
  const userPrompt = buildUserPrompt(question, history, userContext);

  const response = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: {
      'x-api-key': env.ANTHROPIC_KEY,
      'content-type': 'application/json',
      'anthropic-version': '2023-06-01'
    },
    body: JSON.stringify({
      model: 'claude-haiku-4-5-20251001',  // быстрый и дешёвый
      max_tokens: 300,
      system: systemPrompt,
      messages: [{ role: 'user', content: userPrompt }]
    })
  });

  const data = await response.json();
  const answer = data.content[0].text;

  return Response.json({ answer, predictionId: crypto.randomUUID() });
}
```

### Защита: DeviceCheck / App Attest

iOS-приложение получает токен от Apple:
```swift
import DeviceCheck

let token = try await DCDevice.current.generateToken()
// отправляется с каждым запросом в заголовке X-Device-Token
```

Worker валидирует токен через Apple API. Это гарантирует, что запросы идут только из настоящего приложения, а не от ботов.

## 9. Промпт-инжиниринг и персонажи

### Принципы

1. **Системный промпт = душа продукта.** Потратить 2–3 дня на тюнинг.
2. **Каждый персонаж — отдельный промпт.** Тон, лексика, длина ответа.
3. **Безопасные блокировки** — никаких медицинских, юридических, финансовых советов.
4. **Контекст** — последние вопросы передаются в промпт.

### Шаблон системного промпта

```
Ты — [имя персонажа], [роль]. Ты отвечаешь на вопросы о жизни,
любви, работе и будущем в стиле, описанном ниже.

ХАРАКТЕР:
[описание личности]

СТИЛЬ ОТВЕТА:
- Длина: 1–3 предложения, не больше
- Тон: [мистичный / саркастичный / тёплый / драматичный]
- Лексика: [высокий стиль / разговорный / сленг]
- Используй: [метафоры, отсылки к планетам, чакрам, снам]
- Избегай: прямых "да/нет", советов как от психолога

ОГРАНИЧЕНИЯ:
- Никогда не давай медицинских советов. Если вопрос о здоровье,
  скажи в своём стиле: «Звёзды молчат об этом. Сходи к лекарю.»
- Никогда не предсказывай смерть, болезни, катастрофы.
- Не давай юридических и финансовых советов.
- Не упоминай реальные имена политиков, селебрити в негативном ключе.
- Если вопрос неуместный или вредный — мягко уклонись, оставаясь в роли.

КОНТЕКСТ ПОЛЬЗОВАТЕЛЯ:
Имя: {name}
Знак зодиака: {sign}
Последние 3 вопроса: {history}

Текущий вопрос: {question}

Дай предсказание.
```

- Cloudflare KV хранит только хеш device token + счётчик запросов

- Privacy Policy на собственном сайте (можно использовать Notion + кастомный домен)
- App Privacy в App Store Connect:
  - Data Used to Track You: None
  - Data Linked to You: None

## 14. Контроль расходов на API

### Расчёт стоимости одного запроса

Используя Claude Haiku 4.5:
- Input: ~500 токенов (системный промпт + контекст) ≈ $0.0004
- Output: ~150 токенов (ответ оракула) ≈ $0.0006
- **Итого ~$0.001 за предсказание**

Гороскоп (длиннее):
- Input: ~300, Output: ~500 ≈ $0.002

Полный натальный анализ:
- Input: ~1000, Output: ~2000 ≈ $0.011

### Жёсткие лимиты

#### На стороне Anthropic (Spend Limits)
- Установить **hard limit на $50/месяц** на старте
- Email-уведомления при достижении 50%, 80%, 100%

#### На стороне Cloudflare Worker
```typescript
const DAILY_LIMITS = {
  free: 5,
  pro: 100,         // даже Pro имеет потолок
  predictions_per_request: 1
};

const MAX_QUESTION_LENGTH = 500;  // символов
```

#### На стороне приложения
- Проверка интернета
- Очередь запросов (один за раз)
- Кэш гороскопа на 24 часа
- Кэш карты Таро на 24 часа

### Защита от абуза

- DeviceCheck токен на каждый запрос
- Rate limit на устройство (не на IP — спорно с CGNAT)
- Минимальная длина вопроса (3 символа), максимальная (500)
- Блокировка явно мусорных запросов на бэкенде регуляркой
